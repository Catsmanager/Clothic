# Related GitHub Projects

Last researched: 2026-06-09. Refresh this list when the user asks for the latest projects or when the loop depends on current repository state.

## Core Pattern

- `karpathy/autoresearch` - the reference AutoResearch repository. It keeps the setup small: fixed data prep/runtime utilities, one editable training file, one Markdown program file, a fixed wall-clock budget, and `val_bpb` as the lower-is-better metric. GitHub page: https://github.com/karpathy/autoresearch
- `karpathy/nanochat` - parent/sibling compact LLM training project referenced by AutoResearch for broader implementation ideas. GitHub page: https://github.com/karpathy/nanochat
