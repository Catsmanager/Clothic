# Loop
모든 작업은 아래 순서로 수행한다.
## 1. Plan
- 목표 확인
- 수정할 파일 예상
- 위험 요소 확인
## 2. Draft
- 초안 또는 1차 구현 생성
## 3. Review
다음 기준으로 검토한다.
- PRD 범위 안인가?
- CLAUDE.md 규칙을 지켰는가?
- 구조가 단순한가?
- 불필요한 기능이 추가되지 않았는가?
- 테스트 또는 검증이 가능한가?
## 4. Revise
검토 결과를 반영해 수정한다.
## 5. Report
작업 결과를 보고한다.
- 변경 파일
- 변경 내용
- 리뷰에서 발견·수정한 문제
- 검증 결과
- 남은 문제
