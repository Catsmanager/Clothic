# Test Plan

## 기본 검증

### 인증
* 이메일 회원가입이 가능한가
* 이메일 로그인이 가능한가
* 카카오 로그인이 가능한가
* 로그아웃 후 로그인 화면으로 이동하는가
* 미인증 상태에서 홈 화면 접근 시 로그인 화면으로 리다이렉트되는가
* 앱 재설치 후 로그인하면 데이터가 복원되는가

### 핵심 기능
* 홈 화면이 표시되는가
* 코디 생성이 가능한가
* 아이템 선택 시 아바타가 변경되는가
* 코디 저장이 가능한가
* 저장된 코디가 Supabase DB에 존재하는가
* 캘린더 조회가 가능한가
* 월간 통계가 계산되는가
* 잠자는 옷장이 표시되는가

### 보안
* 다른 사용자의 코디·아이템에 접근 불가한가 (RLS 검증)

## 금지되는 결과

* 빈 화면
* 무한 로딩
* 앱 크래시
* 데이터 유실
* 깨진 이미지
* 콘솔 에러
* TypeScript 에러

## MVP 완료 기준

* 코디 생성 가능
* 코디 저장 가능
* 캘린더 조회 가능
