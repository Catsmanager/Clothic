# PRD

## 제품 개요

Clothic은 사용자가 픽셀 아바타를 활용해 매일의 코디를 기록하고, 월간 통계를 통해 자신의 패션 습관을 분석할 수 있는 모바일 코디 다이어리 앱이다.

단순한 옷 입히기 게임이 아닌, 코디 기록과 옷장 데이터 분석에 초점을 둔 라이프스타일 서비스이다.



## 핵심 사용자

* 패션에 관심이 많은 20~30대 여성
* OOTD를 기록하는 사용자
* 자신의 스타일을 관리하고 싶은 사용자
* 옷은 많지만 자주 입는 옷만 반복하는 사용자



## 핵심 기능

* 픽셀 아바타 기반 코디 생성
* 코디 저장
* 날짜별 코디 기록
* 캘린더 조회
* 월간 패션 리포트
* 가장 많이 입은 아이템 분석
* 가장 많이 입은 색상 분석
* 잠자는 옷장 분석
* 스타일 분석
* 챌린지 기능

* 하의 선택
* 신발 선택
* 가방 선택
* 액세서리 선택
* 코디 저장
* 코디 목록 조회
* 코디 상세 조회
* 캘린더 화면
* 월간 통계 화면
* 잠자는 옷장 화면
* 챌린지 화면

## 성공 기준

* 사용자가 코디를 생성할 수 있다.
* 사용자가 코디를 저장할 수 있다.
* 사용자가 캘린더에서 코디 기록을 확인할 수 있다.
* 사용자가 월간 통계를 확인할 수 있다.
* 사용자가 현재 계절 옷 중 오래 입지 않은 아이템(14~29일 관심 필요 / 30일+ 잠자는 옷)을 확인할 수 있다.
* 앱을 종료해도 데이터가 유지된다.
* 앱 재설치 후 로그인하면 데이터가 복원된다.
